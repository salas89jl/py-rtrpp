# Real-Time Robotics Perception Platflorm (RTRPP)
Open-source robotics perception platform capable of processing LiDAR data from prerecorded datasets and live sensors

## Mission:
Design, develop, and document a modular robotics perception plaform capable of processing LiDAR data from both prerecorded datasets and live sensors. The project emphasizes sound software engineering practices, algorithmic understanding, extensibility, and reproducible experimentation, ultimately serving as a foundation for autonomous robotics research and software engineering.

## Dependencies:
- Python 3.10 or higher
- NumPy
- Open3D
- Matplotlib
- pyserial
